# Sample fixtures

Tiny Mecklenburg-like rows so the CLI works **without** calling county GIS.

- `parcels.csv` / `sales.csv` — invented PINs and owners for learning. Not live tax records.
- `docs/` — short public-statute excerpts and original study notes with source URLs.

Live county data: `meck-agent ingest --zip 28202`
Live/public docs: `meck-agent ingest-docs`
